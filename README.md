# Ahanaf-Tanvir-Shovon---Web

Personal portfolio website for **Ahanaf Tanvir Shovon** — Web Developer, Graphic Designer & App Developer. Built with React 19, TypeScript, Vite, and Neumorphism UI design.

## 🚀 Features

- **Neumorphism UI Design**: Tactile dimensional surfaces, recessed input wells, and soft dual-tone shadows.
- **Dynamic Typing Animation**: Interactive hero subtitle showcasing core expertise (Web Developer, Graphic Designer, App Developer).
- **Responsive Layout**: Seamlessly adapted for mobile, tablet, and desktop viewports.
- **Projects & Case Studies**: Interactive case study modal with architecture details and live previews.
- **Interactive Contact**: Direct contact channels with one-click copy and form feedback.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Modern CSS3 / Neumorphic Design System
- **Icons**: Lucide React
- **Linter**: Oxlint

## 💻 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AhanafTanvir/Ahanaf-Tanvir-Shovon---Web.git
   cd Ahanaf-Tanvir-Shovon---Web
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
